# Echoes Studio Website v0.32

## Status
Implemented for review.

## Product specifications implemented

### Read
- Information architecture: Read → Book → Part → Chapter.
- Book One table of contents uses Part sections in a two-column desktop grid and one-column mobile layout.
- Chapter rows are compact and designed to scale to hundreds of chapters.

### Chronicle
Canonical Five Ages:
1. The Age of Elarion
2. The Age of Division
3. The Age of Nations
4. The Age of Humanity
5. The Age of Return

Chronicle is the temporal framework of Elarion, not a duplicate of Lore/History.

### Map
Map is the spatial witness of the same history. It opens in the Age of Elarion rather than the story-era political map. The atlas can switch between the Five Ages. Existing artwork is used as a v1 visual layer; canonical age-specific cartography can replace these visual layers later without changing the page architecture.

## Navigation
CHRONICLE and MAP in all existing top-level headers now point to dedicated /chronicle/ and /map/ pages.
